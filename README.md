# 📖 Kamus & Portal Pembelajaran Bahasa Arab

Aplikasi web responsif untuk rujukan istilah tatabahasa Bahasa Arab, analisis ayat interaktif, dan latihan hafalan secara masa nyata (*real-time*).

---

## ✨ Ciri-Ciri Utama

- **Kamus Istilah & Direktori Abjad:** Carian pantas dan indeks abjad bagi istilah Ilmu Sorof, Ilmu Nahu, serta Penomboran ('Adad).
- **Koleksi Ayat Interaktif:** Analisis perkataan dengan serlahan (*highlight*) kata kunci tatabahasa dan paparan nota definisi dinamik.
- **Mod Hafalan (*Flashcards*):** Kad imbas interaktif untuk latihan hafalan Istilah, Koleksi Ayat, dan Ayat Al-Quran (makna mudah & literal) beserta penjejak kemajuan.
- **Panel Pentadbir (Admin):** Kemas kini data terus daripada pelayar dengan kawalan akses terhad dan pemasa sesi automatik.

---

## 🛠️ Teknologi Digunakan

- **Frontend:** HTML5, CSS3 (Responsif & Kawalan Saiz Teks), JavaScript (Vanilla JS), DOMPurify
- **Backend & Database:** Supabase (PostgreSQL, Authentication & Row Level Security)
- **Hosting:** GitHub Pages
